# Ready to Start and Explore

## Highlights

Prebuilt libraries and required header files packaged in archives.

- Latest stable build: [v1.85.3](https://github.com/thommyho/gRPC_windows/releases/tag/v1.85.3)
- Last stable build requiring only C++11 support: [v1.46.7](https://github.com/thommyho/gRPC_windows/releases/tag/v1.46.7)
- For several modern Visual Studio Compilers:
    - Visual Studio 2026 - `MSVC 145` - from v1.85.0
    - Visual Studio 2022 - `MSVC 143`
    - Visual Studio 2019 - `MSVC 142` - until v1.84.x
    - Visual Studio 2017 - `MSVC 141` - until v1.45.1 (and v1.46.7)
    - Visual Studio 2015 - `MSVC 140` - until v1.45.2
- For both `32- and 64-Bit architectures`
- Convenient with all three build configurations `Release`, `RelWithDebInfo`, `Debug`

What is code without examples - harder to understand, less practical to get stated with, and so on.

- Several easy starter examples from the official gRPC project
    - For `Visual Studio 2022`, `Visual Studio 2019`
    - Tested with gRPC versions v1.42.0 and above
    - Maintained at [Cpp-gRPC-Visual-Studio-Examples](https://github.com/thommyho/Cpp-gRPC-Visual-Studio-Examples)
    - New examples taken directly from the gRPC repository are available on the [v2-next-gen-2022](https://github.com/thommyho/Cpp-gRPC-Visual-Studio-Examples/tree/v2-next-gen-2022) branch - please test and give feedback
    - For older versions of Visual Studio e.g. `Visual Studio 2017` and `Visual Studio 2015` until version 1.45.2
    - `Pre-configured` - Can be used in seconds.
    - `Debuggable` - `RelWithDebInfo` and `Debug` include symbols

## Requirements

One of the compilers:

- Visual Studio 2026 - `MSVC 145`
- Visual Studio 2022 - `MSVC 143`
- Visual Studio 2019 - `MSVC 142` (up to v1.84.x)

gRPC C++ v1.47.0 and later require C++14.

For a better experience use one of the IDEs with one the upper mentioned compilers.
