# Cpp-gRPC-Docs - Static Documentation Viewer

A standalone Windows application that opens the static documentation website for Cpp-gRPC-Windows-PreBuilts.

## Features

- **Standalone executable** - No Python or dependencies required
- **Embedded static site** - All HTML, CSS, JavaScript, and assets are bundled
- **Default browser launch** - Opens your system's default web browser
- **Search functionality** - Includes built-in search (Lunr.js)
- **Dark/Light mode** - Built-in theme toggle

## Building the Application

### Using PyInstaller (Recommended)

```bash
# Build the executable
uv run pyinstaller --name "Cpp-gRPC-Docs" --onefile --windowed docs-open.py

# The executable will be created at: dist/Cpp-gRPC-Docs.exe
```

### Using the Batch Script

```batch
build_docs_app.bat
```

### Using Python Script

```bash
python build_docs_app.py
```

## Running the Application

```bash
dist\Cpp-gRPC-Docs.exe
```

Or create a desktop shortcut to `dist\Cpp-gRPC-Docs.exe`.

## Quick Start with uv

```bash
# Build and run in one command
uv run pyinstaller --name "Cpp-gRPC-Docs" --onefile --windowed docs-open.py
dist\Cpp-gRPC-Docs.exe
```

## Building the Documentation Site First

Before building the app, you need to generate the static site:

```bash
# Build MkDocs site
uv run mkdocs build

# Or deploy to GitHub Pages
uv run mkdocs gh-deploy
```

## Troubleshooting

### "site/index.html not found" error

Make sure you've built the MkDocs site first:

```bash
uv run mkdocs build
```

### Executable doesn't open browser

Check that your default browser is properly configured in Windows Settings.

### Search not working

The search index is generated by MkDocs. Rebuild the site if search is broken:

```bash
uv run mkdocs build --clean
```
